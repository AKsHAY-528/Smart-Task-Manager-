# Smart-Task-Manager-

Smart Task Manager is a desktop-based task management application built using **Java, JavaFX, and SQLite**. The application helps users organize daily tasks with features such as task categorization, progress tracking, and persistent data storage.

It provides an interactive user interface for managing tasks efficiently while maintaining data consistency using a relational SQLite database. The project demonstrates core concepts of **Java application development, UI design with JavaFX, and database integration**.
